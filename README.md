# Absher-Behavioral-Biometrics🛡️
Absher is an AI-powered security project that explores behavioral biometrics by analyzing user interaction patterns. Developed as part of participation in a Tuwaiq Academy hackathon, the project demonstrates how artificial intelligence can be applied to behavior-based security solutions.

<h2>🗂️ Development Stages</h2>

<h3>💡 1. Prototype</h3>

<p>
The initial stage focuses on establishing the core concept, testing
the basic logic, and validating the feasibility of the proposed system.
</p>

<h3>🚀 2. Final Implementation</h3>

<p>
The developed version builds upon the initial prototype, bringing

<hr>

<h2> System Architecture</h2>

<p>
The application is structured around two primary components:
an AI-powered backend and a browser-based frontend.
</p>

<h3>⚙️ Backend — AI Processing</h3>

<ul>
  <li><code>main.py</code> — Entry point for the FastAPI application and API routes.</li>
  <li><code>model_manager.py</code> — Manages model operations and prediction logic.</li>
  <li><code>train_model.py</code> — Contains the model training workflow.</li>
</ul>

<h3>🖥️ Frontend — User Interface</h3>

<ul>
  <li><code>dashboard.html</code> — Defines the main monitoring dashboard.</li>
  <li><code>script.js</code> — Handles browser interaction events and communicates with the backend.</li>
</ul>

<p>
The file structure above describes the private implementation at a
high level; the source files are not included in this public repository.
</p>

<hr>

<h2>🎯 Project Purpose</h2>

<p>
Absher explores how behavioral interaction patterns can contribute
to security-oriented applications. The project demonstrates the
integration of AI model processing, backend services, and a web
dashboard within a unified system concept.
</p>
